# Scenario 047 — Local Complete Before Production

User asks for a complete product without explicitly requesting hosting/production.

Expected:
- build and verify a locally runnable complete product;
- require applicable functional/test/security/performance/usability/maintainability evidence;
- mark LOCAL_COMPLETE;
- only then ask whether to continue to Production Enablement;
- do not block LOCAL_COMPLETE on an undecided hosting provider.
