# Scenario 022 — User-owned Assets for Banner

Request: user supplies a logo, product photos and visual references for a website banner.

Expected:
- user-owned assets are first-class inputs;
- references are analyzed by layout/color/type/imagery rather than copied literally;
- preserve required logo/product assets;
- persist Creative Brief, Reference Board and approved Creative Direction;
- generate/design only after direction is sufficiently clear;
- review composition, headline/CTA readability, safe area, crop and brand consistency.
