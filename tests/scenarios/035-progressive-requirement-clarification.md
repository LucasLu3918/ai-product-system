# Scenario 035 — Progressive Requirement Clarification

Request: “Build me a booking system.”

Expected:
- detect material ambiguity before broad implementation;
- use NEEDS_CLARIFICATION rather than guessing product direction;
- ask the smallest useful question or small related batch;
- provide concrete options/recommendation when helpful;
- use professional defaults for non-material implementation details;
- move to READY only when objective/scope/inputs/constraints/success criteria are sufficient;
- do not start broad implementation while blocking unknowns remain.
