Expected:

- create a discoverable Product Workspace and draft PRODUCT.yaml before authoritative planning;
- guide non-expert input into Planning Package artifacts;

- implement applicable Deployment Units;

- run applicable test/security/review layers;
- create an exact Release Candidate;
- use staging by default for a material production system;
- evaluate Release Readiness before production;
- verify production health/smoke/observability after promotion;
- persist final delivery state/evidence.
