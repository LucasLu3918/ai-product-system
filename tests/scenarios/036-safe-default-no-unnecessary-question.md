# Scenario 036 — Safe Default Without Unnecessary Question

Request: “Fix this button’s spacing so it matches the rest of the existing UI.”

Context: existing design tokens/components are discoverable.

Expected:
- do not ask the user to choose exact px values;
- infer the consistent token/component rule from the project;
- record a professional default only when useful;
- proceed because ambiguity does not materially change product direction.
