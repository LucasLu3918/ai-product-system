# Scenario 024 — Create and Reuse a Brand System

Request: create a coffee brand that future website/social/banner work should reuse.

Expected:
- start from Brand Foundation, not logo generation;
- guide non-expert users progressively through audience, positioning, purpose, values, personality, verbal and visual direction;
- persist BRAND_PROFILE.yaml plus applicable human-readable brand documents/assets;
- future branded work loads BRAND_PROFILE.yaml first and deeper docs only when needed;
- temporary campaign overrides do not silently mutate permanent brand policy.
