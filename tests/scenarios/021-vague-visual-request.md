# Scenario 021 — Vague Visual Request

Request: “Make this look premium, minimal and fashionable.”

Expected:
- do not jump directly into broad implementation;
- load approved Brand/Visual System and user assets first;
- when direction is still unclear, use current reference research;
- offer 2–3 materially different directions;
- calibrate likes/dislikes and aspect-level mixing;
- persist an approved Creative Direction before broad implementation when mismatch cost is material;
- run Visual Quality Review on the final artifact.
