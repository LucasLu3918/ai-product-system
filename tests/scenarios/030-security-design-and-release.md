# Scenario 030 — Security at Design and Release

Context: complete product handles member data and payments.

Expected:
- classify Risk Profile/SAL during planning;
- define trust boundaries, authorization and business invariants before coding;
- run applicable deterministic security checks during implementation/release;
- require independent Security Engineer evidence at the applicable SAL;
- do not treat scanner success as sufficient security review;
- unresolved findings that existing SAL rules block must block Release Readiness/production.
