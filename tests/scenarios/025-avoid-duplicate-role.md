# Scenario 025 — Avoid Duplicate Role

Request: “Add a UI Designer role.”

Expected:
- search current Role/Capability/Skill indexes before proposing creation;
- compare Product Designer, ux-web-design and visual-direction by responsibility, trigger, input/output, authority and review obligations;
- prefer reuse or extension when overlap is high/partial;
- create a new Role only after evidence of distinct responsibility + authority + review obligation;
- record the reuse review when a new item is still recommended.
