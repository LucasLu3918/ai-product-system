# Scenario 065 — Architecture Diagram Impact for Core Change

A Large/Core system change modifies routing, persistence, lifecycle or delivery behavior.

Expected:
- Core Change Proposal explicitly assesses Architecture Diagram Impact;
- Documentation Impact Gate checks Maintainer Mermaid + relevant Human SVG/overview;
- affected diagrams are updated;
- unaffected diagrams are recorded N/A with a reason;
- stale affected architecture diagrams prevent documentation completion.
