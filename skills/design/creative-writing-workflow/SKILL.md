# Creative Writing Workflow (Opt-in)

This is an **opt-in** AIPS adaptation of experimental Matt Pocock methods `writing-fragments`, `writing-beats` and `writing-shape`. It is not silently invoked for normal product or game coding tasks and is not an agent authority or autonomous editor.

1. **Fragments — explore:** gather loose ideas, lines, character motives and scene facts without imposing structure. Label canon vs speculative ideas.
2. **Beats — structure:** arrange selected fragments into concrete narrative turns, tensions, transitions and emotional arcs. Check scene continuity.
3. **Shape — revise:** refine paragraphs, voice, rhythm and sequencing into readable original work. Review against agreed genre, length, characters and acceptance criteria.

Allow short iterative user decisions but do not force exhaustive interviews. Preserve the writer's ownership of themes and final approval. For long-running game stories, link to existing game design requirements and project canon; do not overwrite approved lore. If asked to write only one scene, don't force all three stages. Never promise unattended future drafting, imitate protected text verbatim, or publish without explicit authorization.

## Non-triggers
Unrequested creative writing, TDD/code implementation, asset generation, unsolicited editing of personal drafts or any global automatic workflow.
