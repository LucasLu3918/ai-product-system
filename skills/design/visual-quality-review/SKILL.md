# Visual Quality Review

Independently review an implemented/generated visual artifact against its approved Creative Direction and Brand System.

Common checks:
- hierarchy and composition;
- typography;
- spacing/density;
- color/contrast;
- imagery/icon consistency;
- brand adherence;
- must-have / must-avoid traits;
- asset usage;
- responsive/crop/safe-area behavior when applicable.

Adapt by artifact type:
- website/UI: layout, component consistency, responsive states;
- banner/hero: focal point, headline/CTA readability, safe area, crop;
- social asset: thumbnail readability, platform crop, brand recognition.

Return PASS / PASS WITH COMMENTS / REQUEST CHANGES / BLOCK with concrete evidence.
