# Writing Fragments

Use only when the user explicitly asks to collect or explore raw writing material.

Treat the user's notes, memories, lines, observations and questions as a source pile. Preserve their meaning and distinctive wording. Add a short label only when it helps retrieval. Do not impose an outline, decide a thesis, discard an awkward fragment or turn the pile into prose without permission. Mark gaps as questions instead of filling them with invented facts.

The output is an organized fragment file or a clearly bounded set of fragments, as requested. This Skill is the optional first step in the Fragments → Beats → Shape writing workflow.
