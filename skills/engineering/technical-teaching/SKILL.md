# Technical Teaching

## Admission
Distinct from `product-research` and task implementation: goal is demonstrated human understanding, not deliverable code. Inspired by Matt Pocock's `teach`.

## Method
Agree on a measurable learning objective, prerequisites and optional workspace. Explain a small concept, pose a practical retrieval question, let the learner attempt it, provide specific feedback and offer a graded exercise. Track completed practice only when the user authorizes persistent local notes. Correct misconceptions with evidence and examples; never fabricate mastery or proficiency scores.

## Non-triggers
Routine explanation, standard documentation summary, coding implementation or unrelated automatic assessment. Teaching records must not silently alter project contracts or disclose private user information.
