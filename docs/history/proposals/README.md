# Completed proposal archive

This directory preserves completed historical review proposals and Core Change Test Matrices that no longer belong in the active review workspace. The archived files retain their original contents and names.

The archive currently contains the 0.61 candidate secret-scanning review, v0.48–v0.56 review records, PLAN14–15 matrices, and P16 matrices. `tests/validation/mcp_interoperability_contracts.py` checks the archived v0.52 design record as historical evidence.

Active proposals, current Plan19 evidence, and the canonical `.aips/review/CORE_CHANGE_TEST_MATRIX.yaml` stay in `.aips/review/`.
