# 名詞表

本表協助閱讀者理解文件中的常用名稱。命令、識別碼與 canonical 路徑保留原文，實際行為以連結的規範文件為準。

| English | 繁體中文 | 說明 |
| --- | --- | --- |
| AIPS (AI Product System) | AI Product System | 跨 Agent 的工程工作系統，整理專案脈絡、工作方法與驗證證據。 |
| Runtime | 執行環境 | Agent 所在的 Host 與其可用工具、權限和原生控制。 |
| Harness | 整合框架 | 將 AIPS 共用指示接到不同 Runtime 的組件與流程。 |
| Project Intelligence | 專案脈絡資料 | 可追溯的專案知識與檢索索引；EPHEMERAL 模式保存在使用者外部快取。 |
| Role | 角色 | 描述工作責任與協作方式的可重用指引。 |
| Skill | 技能 | 按需求載入的任務方法；canonical 定義位於各 `SKILL.md`。 |
| Protocol | 協定 | 定義特定流程、決策邊界或驗證要求的規範文件。 |
| Change Impact | 變更影響 | 記錄輸入、輸出、資料、呼叫端與使用端的影響範圍。 |
| Human Authority | 人類授權 | 合併、發布、上線與治理決策保留給人。 |
| Advisory | 建議模式 | 提供證據或診斷，不代表 Host 會強制阻擋操作。 |
| UNVERIFIED | 尚未驗證 | 缺少足夠證據確認該行為；不能當成通過。 |
