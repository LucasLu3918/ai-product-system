# AI Product System Bootloader

Do not load this entire repository.

1. Read `SYSTEM.md`.
2. Run preflight before implementation.
3. Choose one primary work mode unless the request truly spans multiple modes.
4. Resolve only the required roles and leaf skills.
5. For an existing project, discover applicable project instructions before generic knowledge.
6. Load only project context needed for the active task.
7. Never silently invent missing facts or force an unsuitable role to cover missing expertise.
8. Persist required outputs and execution state in the project workspace.

Human project decisions have the highest project authority, subject to external platform/tool restrictions and the protected safety boundary.
