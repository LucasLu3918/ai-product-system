# Product Creation

Use for a new product or major greenfield initiative.

Flow:

```text
Discovery → Product Definition → UX/Visual Direction → Architecture → Delivery/Test Plan → Cross-role Review → Human Planning Approval → Implementation
```

Ask only blocking questions at each stage. Propose professional defaults instead of asking users to supply expert architecture decisions they may not know.

Before implementation, persist a planning package containing the agreed product scope, requirements, UX/design direction, architecture, data/API decisions as applicable, test strategy and implementation sequence.

Implementation begins only after required planning approval.
