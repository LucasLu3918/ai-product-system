# Cost Analysis

Use for infrastructure sizing, hosting comparison and approximate total cost.

Flow:

```text
Workload Inputs → Assumptions → Capacity Model → Architecture Options → Current Provider Pricing → TCO Comparison → Recommendation + Confidence
```

Prices, service limits and current offerings are dynamic knowledge and must be verified at runtime.

Never present false precision. State assumptions, scenario, confidence and missing inputs. Compare operational complexity and reliability, not only monthly price.
