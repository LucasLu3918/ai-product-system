# Delivery Planning

Use when product requirements already exist and the user wants an execution plan rather than rediscovery.

Flow:

```text
Document Intake → Requirement Extraction → Dependency Analysis → Work Breakdown → Milestones → Risks → Execution Order → Review
```

Do not rerun product discovery unless the provided plan has blocking gaps.

Typical outputs: work breakdown, dependencies, milestones, implementation order, risks and release/test checkpoints.
